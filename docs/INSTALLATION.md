# Instalação e atualização
```bash
git clone https://github.com/mxcapellani/Diretor-Fotogr-fico-IA-Ultimate-.git
cd Diretor-Fotogr-fico-IA-Ultimate-
```
Copiar `.agents/skills/diretor-fotografico-ia-ultimate` inteira para o projeto destino; manter referências para cobertura detalhada. Host deve descobrir Agent Skills ou carregar SKILL.md explicitamente. Apenas o arquivo principal oferece núcleo funcional, não todo o texto de origem.
Atualizar preservando alterações locais, consultando CHANGELOG e repetindo validação. Não há assinatura, chave ou Python obrigatório para elaborar prompts. Python/PyYAML são dependências de manutenção; visão e geração dependem do host e ferramentas disponíveis.
