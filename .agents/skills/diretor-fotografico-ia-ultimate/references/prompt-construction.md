## Página PDF 49

```text
FOTOGRAFIA COM IA |




A FÓRMULA
DO PROMPT
PROFISSIONAL


 Um prompt bem estruturado segue uma lógica que facilita a “compre-
ensão” da IA. Aqui está uma fórmula que funciona bem:


    FÓRMULA DO PROMPT

   [Ângulo] + [Posição] + [Enquadramento] +
   of a [sujeito], [roupas/aparência], [ambiente],
   [iluminação], [lente]


  Nem todos os elementos são obrigatórios em todo prompt. Use o que
fizer sentido para a foto que você quer criar. Mas seguir essa ordem aju-
da a manter consistência.




                                                                               49
```
